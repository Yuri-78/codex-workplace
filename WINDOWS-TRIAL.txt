Windows 电脑试用说明

这是独立的演示版，含虚构资料，不需要购买服务器或域名。

1. 从受信任的交付渠道下载试用包，先右键“全部解压缩”。
   不要直接在压缩包内双击，也不要单独打开 static/index.html。
2. 电脑需要 Python 3.12 或更新版本。
   若尚未安装，在 python.org 官网下载安装，安装时勾选 Add python.exe to PATH。
3. 打开解压后的文件夹，双击 start-windows.bat。
4. 浏览器会自动打开本机登录页面。若没有自动打开，复制启动窗口显示的完整地址到 Edge 或 Chrome。
   通常是 http://127.0.0.1:8000；若端口已占用，程序会选择其他空闲端口，以窗口显示为准。
5. 首次启动还会自动打开 initial-accounts.txt。选择 admin 账号及它对应的随机密码登录。
   若没有自动打开文件，进入解压目录下 .data/windows-demo 文件夹，打开 initial-accounts.txt。
   密码只在你的电脑生成，不包含在试用包中。修改密码后，原文件中的密码不再有效。
6. 登录后可先查看已有演示订单，再尝试安排生产、领料、逐工序报工、完工入库和发货。
7. 试用期间保持启动窗口打开。停止时在该窗口按 Ctrl+C；再次双击可继续使用原演示数据。

本机地址只在运行程序的这台电脑上有效，不是公网地址。
所有演示数据保存在解压目录 .data/windows-demo，不会操作其他正式账套。
请保留整个解压目录，不要删除 .data 目录，以免丢失试用数据。
忘记密码可使用 manage_accounts.py 工具，详见 README.md。
